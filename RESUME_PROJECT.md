## LinkedIn Project Description
Built a Retrieval-Augmented Generation (RAG) AI chatbot that lets users upload documents or ingest website content and ask questions based on the provided knowledge base. The system combines document processing, text chunking, vector embeddings, FAISS semantic search, relevance filtering, configurable LLM backends and source references. The project was designed as a local-first AI application using Python and FastAPI.
